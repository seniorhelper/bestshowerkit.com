How we write these

Three rules, because most home improvement content follows none of them.

We name numbers. "Low threshold" is a marketing phrase. "One inch" is a specification. Where we cite outside data, we say where it came from so you can check it.

We say when a cheaper option is right. A flat-pack kit is the correct answer for a rental. A walk-in tub is the correct answer for some people. Saying so costs us occasional sales and buys us better conversations.

We do not invent customers. There are no fabricated testimonials on this site. Where we describe a situation, it is a type of job we quote regularly, described as such.
